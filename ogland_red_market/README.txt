VNL MARKET — site cu bannerul și culorile tale
================================================

Fișiere:
- index.html — pagina magazinului, design negru/roșu/mov, RO/EN, filtre, coș și comandă manuală prin email.
- assets/banner.png — bannerul încărcat de tine.
- assets/logo.png — emblema încărcată de tine.

ÎNAINTE DE PUBLICARE:
1. În index.html caută SCHIMBA-EMAILUL-AICI@example.com și pune adresa ta reală.
2. Schimbă linkul Discord din footer cu invitația ta.
3. Editează ofertele și prețurile demonstrative.
4. Verifică regulile OGLand privind vânzarea conturilor/bunurilor virtuale.
5. Formularul deschide aplicația de email a vizitatorului; nu colectează și nu trimite date pe un server.

PUBLICARE GRATUITĂ CU GITHUB PAGES:
1. Creează un repository GitHub numit vnl-market.
2. Încarcă index.html și folderul assets/ păstrând structura.
3. Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
4. Așteaptă ca GitHub Pages să publice URL-ul.

Plata este MANUALĂ: după primirea cererii, contactezi clientul și trimiți instrucțiunile de plată printr-un canal sigur. Nu cere PIN-uri Paysafecard prin formulare publice și nu pretinde că o comandă este plătită până nu verifici plata.
